# 07 - Mega Menu

Multi-column dropdown menu built from `linklists.main-menu` with optional featured/promo column.

Usage
- Place the markup in your header where the main menu should render and include `styles.css`.

Customization
- Featured column source: `` — add content (image, promo HTML) into the `.mega-menu__col--featured` block or populate via menu-item metafields.

Accessibility
- Desktop: open on hover; Mobile: tap to expand. Ensure keyboard access by tabbing to links.

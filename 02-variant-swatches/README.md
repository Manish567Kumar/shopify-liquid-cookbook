# 02 - Variant Swatches

Replace the native variant picker for color/image swatches.

Usage
- Copy `snippet.liquid` into your product template near your product form.
- Include `styles.css` in your theme assets.

Customization
- Variant color source: `` — set to a variant metafield path if you store hex values, otherwise the snippet falls back to image or name.
- Selected state uses `.var-swatch--selected`.

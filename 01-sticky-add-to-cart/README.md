# 01 - Sticky Add To Cart

Mobile-only sticky add-to-cart bar that appears when the main add-to-cart button scrolls out of view.

Usage
- Copy `snippet.liquid` and `styles.css` into your theme (place the CSS into an appropriate asset and include it).
- Set the `TRIGGER_ELEMENT_SELECTOR` in the top comment of `snippet.liquid` to match your product form submit button.

Customization
- `TRIGGER_ELEMENT_SELECTOR` (in `snippet.liquid`): ``
- Breakpoint to hide the bar (in `styles.css`): `@media (min-width: 768px)` — replace `768px` as needed. /* CUSTOMIZE */

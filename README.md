## 💡 Why this exists

Every Shopify store owner eventually wants the same handful of tweaks — a sticky add-to-cart, variant swatches, a quick-view, a mega menu. The "solution" is usually a $10–30/month app for something that's **20 lines of Liquid**.

This cookbook is a growing collection of **battle-tested, copy-paste snippets** so you can customize your theme yourself and stop renting features.

## 🔧 How to use

1. Browse to the snippet folder you want
2. Read the short README (where to paste, what to change)
3. In Shopify: **Online Store → Themes → Edit code**
4. Paste, save, done ✅

Every snippet is standalone — take only what you need.

> 💡 **Tip:** Always **Duplicate your theme** before editing, so you have a one-click rollback.
